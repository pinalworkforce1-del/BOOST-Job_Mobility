BOOST Honeycomb Employment Preparation v0.7

PURPOSE
A career-preparation / employment-readiness gate, not an occupation recommendation engine.

RUN
1. Unzip the package.
2. Double-click START_BOOST.bat or index.html.

FLOW
Welcome / Honeycomb philosophy
→ participant name + prior-work question
→ top 3 O*NET interests
→ Protect Your Pathway foundation
→ 8 adaptive restaurant scenarios (2 from each top interest + 2 non-aligned exposures)
→ first-choice workplace judgment evidence
→ top 3 demonstrated transferable skills
→ More of this / Still exploring / Less of this
→ Employment Preparation Snapshot
→ Save / Print PDF

WHAT THIS VERSION DOES NOT DO
- no occupation recommendations
- no predicted career doors
- no Future Seeds
- no H3 / Lightcast ranking
- no adjacency scoring

WHY
The module is intended to help participants understand what they bring, decide what they want to nurture, and choose a next employment opportunity that builds useful evidence and skills.

TEST NOTE
This is a logic/UX prototype. The 24 scenario structure and scoring behavior are wired; several scenario images use a clean fallback frame because only a subset of final art assets are currently present in this package. Scenario narration files are included where available.
